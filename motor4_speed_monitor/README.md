# 四电机控制与速度监测

## 计划
从零搭建一个ros可遥控的麦轮机器人

## 软件环境

- STM32CubeMX 6.18.1
- STM32CubeIDE
- STM32 HAL
- FreeRTOS

## 工程入口

- CubeMX 配置：[motor4_speed_monitor.ioc](motor4_speed_monitor.ioc)
- 主程序：[Core/Src/main.c](Core/Src/main.c)
- 电机控制：[Core/Src/motor.c](Core/Src/motor.c)
- 电机控制接口：[Core/Inc/motor.h](Core/Inc/motor.h)
